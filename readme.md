# Excel 差异对比工具（专业增强稳定版）

一个用于 **对比两个 Excel 表格差异** 的桌面工具。

专为：
- 考勤对账
- 财务报表核对
- 合同金额校验
- 数据同步验证
- OA / ERP 导出结果比对

等场景设计。

---

# ✨ 功能特性

✅ 图形界面（GUI，一键操作）  

✅ 支持多 Sheet 自动对比  

✅ 支持联合主键（如：工号 + 日期）  

✅ 支持忽略列（更新时间/操作人等）  

✅ 自动生成 diff_result.xlsx  

✅ 修改记录 **双行旧/新展示 + 黄色高亮差异

✅ 无线程设计，稳定不崩溃  

✅ 可打包为 exe

---

# 📊 输出效果说明

生成文件：

包含：

| Sheet    | 含义                           |
| -------- | ------------------------------ |
| xxx_新增 | 新文件多出的记录               |
| xxx_删除 | 新文件缺少的记录               |
| xxx_修改 | 旧/新两行对比 + 黄色标记差异 ⭐ |
| 汇总     | 统计信息                       |
